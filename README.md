# Stundenplan

Filmakademie schedule as a phone-friendly web page, refreshed from ev3nts every 2 hours by GitHub Actions.

- Site: https://fa-plan.github.io/
- Calendar feeds: `Filmakademie-alle.ics` (all) and `Filmakademie-Pflicht.ics` (mandatory only)

Secrets used by the workflow: `FA_USER`, `FA_PASS`.
